# Beginner UX check

Ask a friend who has not used the app to try these steps without coaching.

## Five-second check

- Show the first screen for five seconds, then hide it.
- Ask what the app helps them do. They should say it helps them chat with an AI.
- Ask what they would do next. They should find the first setup step.
- Ask what each visible navigation item means:
  - **Home** — see what to do next.
  - **Chat** — write a message and get an answer.
  - **Models** — find an AI and check if it works.
  - **AI Keys** — connect an AI service.
  - **Settings** — change how the app works.

## First chat in two minutes

- Start with a new account that has no saved AI keys.
- Time how long it takes to get from Home to an answer in Chat.
- Check that the person can find a key-help link, add a key, unlock it, and send a short message.
- Aim for less than two minutes after the account is ready and the person has an AI key.
- Note any words or steps that need an explanation.

## Optional advanced features

- Turn on **Show advanced features** in Settings.
- Check that **Backup Plans** and **History** appear in the navigation.
- Turn the setting off and check that those items disappear.
- Open a saved History row and make sure it shows details only, never message text.

## Error message

- Try a wrong AI key.
- Check that the message says what happened and what to do next.
- Make sure it does not show a raw error, status code, or stack trace.

## Chat on different screens

- Open Chat at phone width (320–430 px), tablet width, and desktop width.
- Check that the model selector, chat messages, and message box fit without horizontal page scrolling.
- On a phone, open and close **More options** and confirm the message box remains usable.
- On desktop, confirm model settings stay beside the conversation and only the conversation needs to scroll as it grows.
- Send a long reply and confirm the newest content remains visible while streaming.
- Confirm the answered-model and fallback details do not reduce the conversation's available height.

## Model filters

- Open the Models filter menu and select multiple AI services, or use **All AI services** to select/deselect them together.
- Combine provider selections with **Free only** and **Favorites**; confirm the result count and model list update.
- Check that the filter menu fits within the viewport and can scroll on small screens.
